# Niral Thiruvizha — Startup Knowledge Base

A personal knowledge repository containing learning materials, reference documents, frameworks, and resources collected while learning and working through **Niral Thiruvizha**.

This repository preserves the knowledge and resources gathered throughout the entrepreneurship and startup-building journey, from identifying real-world problems to understanding customers, building teams, finding mentors, developing solutions, storytelling, and scaling.

---

## About

This repository was created to organize and preserve the materials studied and collected during the **Niral Thiruvizha** learning and startup-building journey.

The resources cover different stages of the entrepreneurial process, including:

- Design Thinking
- Innovation
- Industry analysis
- Problem identification
- Problem analysis
- Customer segmentation
- Startup team building
- Finding co-founders and mentors
- Storytelling and pitching
- Business development
- Startup scaling
- Entrepreneurship frameworks and methodologies

The repository acts as a **personal reference library** that can be revisited when working on future startup ideas, projects, hackathons, and product-building activities.
